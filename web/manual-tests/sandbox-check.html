AC8 manual verification

PRD.md AC8: "An HTML artifact containing <script>fetch('https://example.com')</script> renders inert with the request blocked." Verification method per the PRD: manual test with the browser network panel — this page exists to make that test reproducible without the full app running.

This page constructs the exact same sandbox the app uses in web/src/components/ArtifactViewer/HtmlFrame.tsx and web/src/components/ArtifactViewer/sandboxHtml.ts: an <iframe sandbox="allow-scripts" srcdoc="…"> (no allow-same-origin, ever), wrapping a malicious payload inside the same CSP-injecting template the real app uses.

Steps

  1. Open this file directly in a browser (no server needed): file://…/web/manual-tests/sandbox-check.html.
  2. Open DevTools → Network tab, and enable "Preserve log".
  3. Reload this page.
  4. Watch the box below and the Network tab for 3 seconds.

Expected result

The status box below must read "fetch blocked", and the Network tab must show no request to example.com of any kind (not even one that fails with a CSP error — a correctly-configured default-src 'none' CSP combined with the opaque sandboxed origin prevents the request from ever being dispatched, it does not merely fail after being sent).
